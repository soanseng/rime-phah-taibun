# 網頁工具：轉換、寫作檢查、詞彙、文法、檢定練習

<p>轉換、寫作檢查、詞彙、文法、檢定練習這幾个網頁工具是純靜態網頁：詞典佮語料模型隨頁面載入，一切計算攏在你的瀏覽器內底，無後端。</p>

<h3>名詞：漢羅、TL、POJ</h3>
<ul>
<li><strong>漢羅（Hàn-lô）</strong>：漢字佮羅馬字混合書寫的台文書寫方式——是一个「用啥物字寫」的慣例，毋是一套拼音系統，也無官方標準。轉換工具做的正是「文字層（漢羅）⇄ 拼音層（TL／POJ）」的轉換。</li>
<li><strong>TL＝臺羅</strong>：教育部《臺灣台語羅馬字拼音方案》，民國 95 年（2006）公告，原名《臺灣閩南語羅馬字拼音方案》，113 年（2024）8 月 26 日函修正改今名；整合台灣語言音標方案（TLPA）、白話字佮國際音標，日常簡稱「臺羅／台羅、TL」。</li>
<li><strong>POJ＝白話字（Pe̍h-ōe-jī）</strong>：19 世紀傳教士制定的教會羅馬字，學術文獻嘛叫「教會羅馬字（教羅）」；台語教會文獻佮台語文學長期用伊書寫。本站的 POJ 輸出用正式字形（o͘、ⁿ）。</li>
</ul>

<h3>漢羅 → 台羅 TL／白話字 POJ</h3>
<p>用 82,000 外詞的詞典做<a href="https://github.com/soanseng/rime-phah-taibun" target="_blank" rel="noopener">最長匹配斷詞</a>：每一冬漢字對著一組讀音，<strong>點漢字會使循環切換讀音</strong>（方言變體攏接收）；詞典揣無的字顯示 ⟨?⟩。逐音節的調符定位（oo 標頭一个 o、iu/ui 標第二母音……）是對寫台文輸入法的 Lua 核心 1:1 移植。全羅 POJ 閣進一步用<strong>正式字形</strong>：oo→o͘、鼻化 nn→ⁿ、ts→ch、tsh→chh、ing→eng、ua→oa、ue→oe，調符照 POJ 慣例重新定位（gōa、hōe、chúi；有韻尾照舊標 a／e：koán、goe̍h）——佮寫台文的全羅 POJ 輸出仝款。</p>

<h3>羅 → 漢（實驗功能）</h3>
<p>台羅佮 POJ <strong>免勾選</strong>——輸入先經拼法正規化（ch→ts、oa→ua、eng→ing……）了後，走<strong>仝一條</strong>統計解碼管線，實測兩種拼法輸出逐字相同。解碼是整句 lattice（beam search）：</p>
<ul>
<li><strong>相鄰詞 bigram</strong>：上述語料加上對詞典長詞條（親像「減肥計畫」）切詞自生的搭配統計</li>
<li><strong>調號比對</strong>：你有拍調（親像 <code>sin1-bun5</code>）的時，讀音調號全對的候選加分——按呢「新聞」佮「訊問」（sin1-bun5 vs sin7-bun7）就分會開</li>
<li>分數是正規 log 機率，無「切愈濟詞分數愈懸」的偏差；未命中的音節<strong>保留原音原字</strong>，標點、斷行原樣</li>

</ul>
<p>實測（四篇真實文章，嚴格配對）：88.4／89.4／89.0／83.4% 字元相似（醫學篇因複合詞多略低）——毋過這是實驗功能，<strong>同鍵同調的同音詞</strong>（儲存/除船、濟/坐）愛靠閣較濟語料才選會對，請用佮「輔助對照」的心情來用。</p>

<h3>文法檢查佮教學（轉換頁輸入區，建議性質）</h3>
<p>輸入漢羅了後，輸入區下跤自動生一區<strong>文法檢查佮教學</strong>：① <strong>華語句式</strong>——佮寫作檢查共用仝一套句式規則（V得→V甲、…了嗎→…矣未、可以→會使、比較句愛有「較」、他→伊……），逐條會使點「看文法」；② <strong>建議檢查——華語用字／直譯</strong>——比對華台對照表（上長片語優先，按呢「有沒有」著了，「沒」「不」就袂閣重複列）；③ <strong>輕聲標記建議</strong>——干焦句尾的輕聲詞；④ <strong>可能用著的文法點</strong>——照文法筆記的觸發詞掃，點 chip 跳去文法頁。①②③攏用轉換已經切好的詞把關：詞典長詞內底的字袂報（「實在」的「在」、「不時」的「不」），「了」干焦句尾才報，數詞後的「把」（三把）是量詞。遮是純規則比對，毋是語法解析：攏是「建議檢查／可參考」。</p>
<h3>文法筆記佮語法點檢索</h3>
<p><a href="grammar/">文法</a>頁有兩段：<strong>文法筆記</strong>是本站整理（說明自寫、分類自訂），例句優先採教育部臺灣台語常用詞辭典真實句（逐句標〔教典〕，連官方華語對譯照原句重刊，CC BY-ND 3.0 TW，標示來源），無適配句的主題用自造短句（標〔自造〕）；其他參考逐篇標示——TGGL 語法點／語法小專欄（臺灣台語語料庫應用檢索系統，國家教育研究院，謹此致謝教育部）、維基學院《閩南語文法》（CC BY-SA 4.0，採閩拼系統）、廖淑鳳（2007）臺師大碩論、郭永錕（2016）高雄市教育局講義、塗豆仁學台語（2024-10-03）臉書短文、李淑鳳（2013）〈台語連詞和副詞的關聯性〉（《台灣學誌》第7期）——TGGL、臉書佮論文的例句無重刊。<strong>語法點檢索</strong>是 TGGL 的書目索引（253 點），依原站授權條款語法說明佮例句無重刊，點「原文」連去原系統查閱。</p>

<h3>英文詞按怎處理</h3>
<p>dopamine、nicotine、CNN 這類<em>多音節專名</em>因為袂命中任何台語音節鍵，會自動原樣保留；短字（in、to）有機會拄著台語音節予人轉做漢字——欲保險就用<strong>反引號</strong>包起來：<code>`CNN News`</code> 保證原樣。</p>

<h3>變調佮輕聲</h3>

<p>預設輸出<Strong>本調</Strong>（辭典形）。勾「變調（句內連讀）」會照主流腔規則連讀：句內非尾詞全部音節變調（1→7、2→1、3→2、5→7、7→3；入聲 p/t/k 4↔8、h 尾 4→2/8→3），句尾詞上尾音節保持本調；輕聲詞（親像「轉去」→ <code>tńg--khì</code>）自動用 <code>--</code> 標示。詞組/情感變調猶未支援，屬近似。</p>

<h3>寫作檢查</h3>
<p><a href="check/">寫作檢查</a>頁接受台羅、白話字、漢羅抑是混寫，逐項列出建議（建議性質，最後由你決定）：① <strong>拼音系統</strong>——仝一篇台羅佮白話字混用，就共少數彼款標出來，會使一鍵統一做 TL 抑是 POJ（外語詞 Door、Formosa 無算）；② <strong>數字調</strong>（tsiah8）轉調符；③ <strong>調號佮韻尾</strong>——p/t/k/h 尾干焦會使是第 4、第 8 聲；④ <strong>調符位置</strong>（無系統記號的詞 súi、tùi 照全文系統判）；⑤ <strong>詞典揣無的音節</strong>，提供相近的寫法；⑥ <strong>連字符</strong>——干焦教典詞目才建議；教典例句若較定分開寫（「毋是 m̄ sī」），就算是詞目嘛袂建議；例句無出現的詞目照詞目的連字號寫法；⑦ <strong>推薦用字</strong>——教育部推薦用字 700 字詞的異用字（親像 𣍐→袂）佮詞內底的華語字（這個→這个，讀音佮推薦字仝才提醒、換了後愛是詞典詞），干焦佇斷詞結果是單獨詞的時才提醒，「重要」的「要」袂誤報；⑧ <strong>華語直譯佮輕聲</strong>，佮轉換頁仝一份對照表、仝款把關；⑨ <strong>華語用字</strong>——詞典揣無讀音的漢字（阿嬤）標出來，照辭典華語義建議台語寫法（阿嬤→阿媽）；⑩ <strong>華語句式</strong>——跑得很快→走甲真緊、你吃飽了嗎→食飽矣未、是誰→啥人、他比我高→伊比我較懸……逐條連去文法筆記。</p>
<p><strong>舊式寫法（提醒）</strong>：白話字雙元音 oa／oe／ui 的調符，舊文獻（親像 1925 年蔡培火《十項管見》寫 Tâi-ôan、教會公報寫 toā、tuì）有另一派囥法——毋是拍毋著，檢查會用「舊式寫法」列出來，提醒現代白話字的標準寫法（Tâi-oân、tōa、tùi），欲改才採用。</p>
<p>用字規範兩模式：揀「教育部 700（全漢字）」是全漢字書寫，「的（ê）」「个（ê）」攏是推薦字，袂叫你改 ê；揀「LKK 漢羅」就照李江却基金會用字表，推薦字 LKK 表建議寫羅馬字的（ê、bē）會直接建議改寫（所以 我的 建議 我 ê），而且干焦佇讀音佇的所在——「目的 bo̍k-tik」的「的」袂冤枉。模式說明顯示佇選單下跤。</p>
<p>檢查規則有用真實語料量過（教育部教典例句 900 句均勻抽 200 句；這批例句嘛有用來調規則，所以是護欄，毋是獨立的準確率）：教典台文受點 8%（大部分是句尾輕聲標記建議）、教典台羅 1.5%、仝批例句的華語翻譯 88.5% 有標。測試有共這幾个比率設門檻，規則若變吵會先擋落來。華語句式規則干焦是建議，無逐條各別量過準確率。</p>

<h3>檢定練習</h3>
<p><a href="study/">檢定練習總覽</a>照教育部臺灣台語語言能力認證的四項測驗（聽力、口語、閱讀、書寫）整理工具，毋是官方題目：</p>
<ul>
<li><strong>聽寫</strong>（<a href="try/#listen">網頁試拍・聽寫</a>）：放教育部《臺灣台語常用詞辭典》例句原音，用網頁試拍（免安裝的 Rime 輸入法）拍出漢羅抑是羅馬字，拍著的字隨現，Enter 揭曉答案。例句文字佮音檔照原文原音引用（CC BY-ND 3.0 TW），音檔轉做單聲道 32 kbps MP3。</li>
<li><strong>打字練習・模擬考</strong>（<a href="try/#practice">網頁試拍・練習</a>）：看讀音拍整句、逐字標對錯；模擬考干焦看漢羅。</li>
<li><strong>推薦用字選擇</strong>：教育部《臺灣台語推薦用字700字詞》的建議用字佮異用字做選項；挖空的例句干焦用新北市900例句（MIT），700 表的用例照原文顯示。</li>
<li><strong>華語→台語造句</strong>：看華語寫台語，才對照參考答案，家己評。</li>
<li><strong>變調練習</strong>：逐字顯示本調佮變調（規則佮轉換頁仝款），會使家己點字設定調組界線；閣有變調小測驗——題目對教育部教典例句（佮聽寫仝批）揀連字號連做伙的 2–3 音節詞，連讀時詞內非尾音節一定愛變調，答案無歧義，閣附原句做語境。</li>
<li><strong>弱點複習</strong>：各練習拍毋著、揀毋著的字詞變做複習卡，照間隔重複（Leitner 格仔：答著 1、2、4、8、16、32 工後閣出，答毋著 10 分鐘後閣出）；讀音卡會分析錯佇聲調、送氣、聲母、韻母抑是鼻音。</li>
<li><strong>學習單列印</strong>：書寫測驗是紙筆作答，印對照、挖空、華語→台語學習單手寫練習。</li>
</ul>
