常見問題

試拍進前，先看這。Būn-tê

網頁試拍佮安裝版有啥物無仝？

引擎佮 Lua 模組攏仝款；網頁版用精簡字典（約 4.5 萬詞＋常用單字），無注音反查、Emoji 佮造詞。欲用完整 22 萬詞字典，請安裝寫台文。

我拍的字會傳去伺服器無？

袂。輸入法引擎編譯做 WebAssembly，攏佇你的瀏覽器內底行；字典第一擺下載了後囥佇瀏覽器快取。

手機會使試拍無？

網頁試拍需要實體鍵盤。手機請用 Android 版「寫台文 Trime」，見安裝的 Android 分頁。
