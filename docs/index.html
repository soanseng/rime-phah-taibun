特色

對輸入到揀字，簡單閣順手。Ti̍k-sik

01

白話字、台羅攏會通

免揀拼音系統：tsiah、chiah 攏揣會著「食」。

02

聲調先免拍

先拍音節揣候選，需要才補數字調，親像 ho2。

03

候選標示讀音

揀字的時看會著拼音註解，順紲確認讀音。

04

漢羅混寫，自動嘛會當手動

預設照 LKK 規範自動混寫；切「手動漢羅」了後，佗一个詞欲寫羅馬字，予你家己標記。

05

整句輸入，一次送出

整句羅馬字攏拍好，按空白鍵就送出；中途嘛會當用 Tab 挑字。

06

標點、符號、Emoji 攏有

漢羅模式全形標點拍了隨出；` 開 50 類符號，`e 揣 Emoji，拍「台灣」會當選 🇹🇼。

  • ? 萬用查字——佗一个位置攏會當查音節
  • 字典查無？用 - 斷音節，Tab 逐字揀，揀字就是揀調
  • -- 輕聲隨拍隨出——「轉--來」「食--飽」無問題
  • 手動漢羅——Tab 反白詞了後按 \ 共伊標記做羅馬字
  • Ctrl+標點 臨時翻轉標點寬度

安裝

先裝 Rime 核心，才加入寫台文。An-tsong

寫台文毋是另外一个輸入法引擎，是 Rime 的台語方案：Windows 用小狼毫，macOS 用鼠鬚管，Linux 用 fcitx5-rime／ibus-rime，Android 用 Trime。

Windows：小狼毫 Weasel ＋ 安裝包或 PowerShell

  1. 一般使用者：從 Releases 下載 PhahTaiBunSetup.exe 雙擊安裝。電腦還沒有小狼毫 Weasel 時，安裝包會自動一起安裝（會跳一次系統管理員權限確認，按「是」）。
  2. 或先自行安裝小狼毫，再於 PowerShell 貼上：irm https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/install_windows.ps1 | iex（互動式：會詢問要安裝寫台文、嘸蝦米 rime-liur 或兩者都裝；修改設定前會先備份 default.custom.yaml，既有輸入法可保留）。
  3. 把系統輸入法切到小狼毫，重新部署 Rime，按 F4 或 Ctrl+` 選「寫台文(台)」。

macOS：鼠鬚管 Squirrel ＋ 指令（沒有 .pkg）

  1. 先裝鼠鬚管 Squirrel。
  2. 在終端機貼上：curl -fsSL https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/scripts/install_macos.sh | bash
  3. 也可以 git clone 之後執行 ./install.sh，或把 schema/、lua/、rime.lua 複製到 ~/Library/Rime/ 後重新部署。
  4. 把輸入法切到鼠鬚管，按 F4 或 Ctrl+` 選「寫台文(台)」。

Linux：fcitx5-rime 或 ibus-rime

git clone https://github.com/soanseng/rime-phah-taibun.git
cd rime-phah-taibun
./install.sh

Android：寫台文 Trime APK（只在 GitHub）或官方同文＋一鍵包

  1. 最省事：安裝客製 APK——從 rime-trime-taigi Releases 下載 arm64-v8a 版（大多數手機；模擬器用 x86_64），允許「安裝未知應用程式」後安裝。寫台文＋注音＋嘸蝦米全部預裝、介面繁體化、點候選直接上屏，長按中文鍵有寫台文面板，不必再部署。
  2. 要自動更新：用 Obtainium——F-Droid 安裝 Obtainium，加入 app source https://github.com/soanseng/rime-trime-taigi，開啟「Filter APKs by CPU Architecture」（預設）就會選到正確的架構，之後自動抓新版。
  3. 啟用「寫台文 Trime」輸入法，方案已預選，直接輸入 gua beh khi tshit tho →「我 beh 去 tshit-thô」。漢羅↔全羅、TL↔POJ 長按中文鍵開面板切換。

替代：官方同文＋一鍵包——F-Droid 安裝 com.osfans.trime，從本專案 Releases 下載 PhahTaiBun-Trime.zip（或加嘸蝦米的 -liur 版）解壓到 Android/data/com.osfans.trime/files/rime，重新部署後選「寫台文(台)」。 完整步驟、路徑與按鍵對照。

更新寫台文

Windows 覆蓋安裝最新 PhahTaiBunSetup.exe 或重跑 PowerShell；macOS 重跑 curl 指令；Linux git pull --ff-only && ./install.sh；Android 用最新的 PhahTaiBun-Trime.zip 覆蓋後重新部署。每個 Release 附 SHA256SUMS 可驗證下載。

一个人的計畫，予閣較濟人寫台文。Tsi̍t-ê lâng ê kè-uē

寫台文由 陳璿丞醫師 發起——一个屏東大漢囡仔，想共母語揣轉來，嘛想共台語書寫對「懂規則的人才會用」推向前「會講台語就會曉開始」。專案整合 Rime、ChhoeTaigi 詞庫、語料頻率、LKK 用字規範佮 21 个 Lua 模組。

本底我攏用嘸蝦米，用甲真慣勢；Linux、Windows、Mac 嘛用 Rime 用真濟冬。10 外年以前，我猶真菜的時陣，捌掠準講家己會曉寫一个台語輸入法——hit 陣失敗矣。這馬有 AI，資源嘛一年一年閣較濟，我就寫一个家己會用的：家己拍字的艱苦、學習過程的艱苦，攏囥佇這个輸入法內底，一邊開發、一邊重學。所以這个方案是照我的環境做的：嘸蝦米佮寫台文做伙用，主要 Linux 佮 Android，Windows 有時仔爾爾。

另外一爿，真濟台語文學冊誠讚：漢羅看有，拼音煞袂曉——想學，著愛一字一字查；顛倒來看 POJ、TL 的時，閣想欲緊知影意思。所以我共輸入法的字典提來，閣做幾个網頁工具：漢羅⇄羅馬字轉換、詞彙查詢、文法筆記，佮會當練習、考試的網頁試拍。橫直，遮攏是我任性、做予我一个人用的。

常見問題

拍字進前，先看這。Būn-tê

寫台文適合完全不懂台文的人嗎？

會講台語、知道大概怎麼拼，就可以開始。候選拼音註解、聲調省略與華語反查，都是為了降低入門門檻。

一定要學 Telex 調鍵嗎？

不必。預設「寫台文(台)」用無調和數字調就夠用。Telex 是 F4 裡的平行進階方案，給熟台羅、想連續補調的人；詞典和輸出與主方案相同，說明見Telex 段。

這是手機輸入法嗎？

官方安裝包只有 Windows（PhahTaiBunSetup.exe）。macOS 用指令安裝，Linux 用 ./install.sh。Android 有客製 APK「寫台文 Trime」，只發佈在 GitHub Releases（F-Droid／Google Play 皆未上架），寫台文＋注音＋嘸蝦米全部預裝、免部署，也可用 Obtainium 自動追新版；或安裝官方同文 Trime／小企鵝 5 ＋ RIME 外掛，再從本專案 Releases 下載 PhahTaiBun-Trime.zip 一鍵包放入後重新部署。完整步驟見 Android 部署。

會覆蓋我原本的 Rime 設定嗎？

安裝流程會保留既有 Rime 輸入法、自訂詞庫與 rime.lua，再加入寫台文方案。

教育部輸入法的增補詞庫匯入後，操作方式也一樣嗎？

不一樣。寫台文只把有用的詞庫資料納入建置流程；操作仍維持寫台文設計：數字鍵打聲調，候選選字按 Tab 後用 asdfghjkl;，符號選單按反引號。

寫台文是原本的拍台文嗎？和 PhahTaigi 有關係嗎？

寫台文（Siá Tâi-bûn）是本專案的新名稱，舊名「拍台文」（Phah Tâi-bûn），改名後下載、更新與設定方式都不變。它與另一款手機 App「PhahTaigi 台語輸入法」是不同開發者的獨立軟體，兩者沒有關聯。
