Windows / macOS / Linux 電腦台語輸入法

會講台語，就會開始用台語輸入法打台文。

拍台文是基於 Rime 的台語輸入法方案。白話字 POJ、台羅 TL 可以混著打，聲調可以先省略，候選區會顯示完整讀音，預設輸出適合日常書寫的漢羅混寫。

會曉講 Tâi-gí，就會曉 phah Tâi-bûn。

為電腦書寫台文設計

幫助你跨過台文打字最困難的幾步。

01

POJ/TL 都會通

不用先決定白話字或台羅。打 tsiah 或 chiah 都能找到「食」，適合不同拼音習慣的人一起用。

02

聲調可省略

先照口語直覺輸入，候選會列出可能聲調；需要精準時再補數字調，例如 ho2、tai5 uan5。

03

候選顯示讀音

每個候選都顯示拼音註解，讓你在選字時確認讀音，也能慢慢建立自己的台文書寫習慣。

04

預設漢羅混寫

依 LKK 李江却用字規範，該用漢字的用漢字，該留羅馬字的留羅馬字，更貼近日常台文書寫。

05

站在開源台文資料上

主字典整合 ChhoeTaigi 9 本辭典、教育部 KipSutian 詞目與建中詞庫增補；候選排序再加權楊允言詞頻、iCorpus 新聞、NMTL 文學等 7 個語料庫。拍台文把台文社群多年累積，變成一套可用的電腦輸入法——數字見下方。

06

人工增補詞庫

建置流程可納入第三方人工整理的教育部輸入法增補 CSV，轉成可驗證的 Rime 詞條，並保留跳過列與重複列報告。

  • ? 萬用查字——任何位置都能查音節
  • 字典查無？用 - 斷音節，Tab 逐字選，選字就是選調
  • -- 輕聲即時生成——「轉--來」「食--飽」攏無問題

可以用，也可以不用

Telex 調鍵：熟台羅的人可選，新手完全不必學。

Telex 來自打字機和電傳線路都沒有越南文字母可用的時代：用字母後面多打一顆鍵來標聲調。拍台文把同一想法做成平行進階方案——主方案「拍台文(台)」維持無調／數字調；F4 另選「拍台文(Telex)」才啟用調鍵。詞典、詞頻、漢羅輸出完全共用。

比較：意傳 / 教育部 / 信望愛 / 拍台文

更適合「想在電腦上真的開始寫台文」的人。

台語輸入法不是只有一種需求。教育部適合查標準與手機輸入，信望愛是成熟的台語客語桌面輸入法，意傳累積了重要的台文 NLP 工具；拍台文則把開源辭典、語料詞頻、Rime 跨平台和低門檻安裝整合成一套電腦輸入體驗。

搜尋：意傳台語輸入法

相較意傳舊方案：拍台文更聚焦日常輸入

意傳的臺灣言語工具、KeSi 和相關台文處理工具奠定了羅馬字轉換、文本正規化、斷詞與 NLP 基礎。拍台文延續這個開源方向，但產品焦點放在「裝好後每天打字」：Rime 方案、POJ/TL 混打、漢羅候選、注音反查、安裝包與跨平台部署。

搜尋：教育部台語輸入法

相較教育部：拍台文更偏電腦創作工作流

教育部的官方資源很適合查標準用字、台羅拼音和手機/平板輸入；既有漢字輸入法也以教育部臺羅和推薦用字為準。拍台文則主打桌機長文輸入：Windows、macOS、Linux 都可用，POJ/TL 不必分開，候選顯示拼音，數字鍵保留給聲調，選字用 Tab 加 asdfghjkl;。

搜尋：信望愛台語輸入法

相較信望愛：拍台文更容易擴充與協作

搜尋：最好用的台語輸入法

拍台文強在低門檻和資料厚度

打字時可以省聲調、POJ/TL 混打、看拼音註解、切換漢羅/全羅、用 ? 任意位置查字；背後用 218,151 個詞條和多語料庫詞頻把常用詞往前排。對創作者、老師、學生和社群小編來說，重點是少查字、少切換、少整理格式。

下載與安裝

先裝 Rime 核心，再加入拍台文方案。

拍台文不是另一個輸入法引擎，而是 Rime 的台語方案。Windows 使用小狼毫，macOS 使用鼠鬚管，Linux 使用 fcitx5-rime 或 ibus-rime。Android 要先自己裝一個 Rime 前端（同文 Trime：F-Droid 或它自己的 Releases），再把 PhahTaiBun-Trime.zip 一鍵包解壓進該前端的 Rime 使用者資料夾後重新部署。

Windows：小狼毫 Weasel + 安裝包或 PowerShell

  1. 先安裝小狼毫 Weasel。
  2. 一般使用者：從 Releases 下載 PhahTaiBunSetup.exe 雙擊安裝。
  3. 或打開 PowerShell，貼上：irm https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/install_windows.ps1 | iex
  4. 這行指令是互動式的：可選裝拍台文（1）、嘸蝦米 rime-liur（2）或兩者（3，預設）；改設定前先備份 default.custom.yaml，並詢問要保留哪些既有輸入法（可保留注音）。
  5. 把系統輸入法切到小狼毫（圖示【中】），重新部署 Rime，按 F4 或 Ctrl+` 選「拍台文(台)」。

macOS：鼠鬚管 Squirrel + 指令（無 .pkg）

  1. 先安裝鼠鬚管 Squirrel。
  2. 打開「終端機」，貼上：curl -fsSL https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/scripts/install_macos.sh | bash
  3. 也可 git clone 後執行 ./install.sh，或把 schema/、lua/、rime.lua 複製到 ~/Library/Rime/ 後重新部署。
  4. 把系統輸入法切到鼠鬚管（圖示【ㄓ】），按 F4 或 Ctrl+` 選「拍台文(台)」。

Linux：fcitx5-rime 或 ibus-rime

git clone https://github.com/soanseng/rime-phah-taibun.git
cd rime-phah-taibun
./install.sh

Android：先裝同文 Trime，再放進拍台文（無 APK）

  1. 先裝輸入法 App：拍台文不含 APK，要用現成的 Rime 前端，而同文 Trime 不是手機內建，得自己裝：
    • F-Droid：com.osfans.trime（最省事，之後能自動更新）
    • 或到同文自己的 GitHub Releases 下載 APK 手動安裝
    裝完到系統設定 → 語言與輸入 → 啟用同文並切過去。替代方案：小企鵝輸入法 5 + RIME 外掛（說明）。
  2. 從本專案 Releases 下載一鍵包，兩種自己選：PhahTaiBun-Trime.zip（拍台文＋注音）或 PhahTaiBun-Trime-liur.zip（再加嘸蝦米，約 20 MB）。解壓進同文的 Rime 使用者資料夾 Android/data/com.osfans.trime/files/rime；Android 11+ 的檔案總管進不去那個目錄，請用電腦 USB／MTP 或同文內建檔案管理。default.custom.yaml 已用 @next 追加好方案，不必自己改。
  3. 同文的選單 → 重新部署。第一次要編譯約 5 MB 字典，會跑幾分鐘，不要把 App 滑掉。
  4. 在方案清單選「拍台文(台)」就能打字。漢羅↔全羅、TL↔POJ 在 App 的開關面板切換（不是桌面的 F4），台文↔英文用中英鍵。
  5. 手機鍵盤沒有桌面快捷鍵，功能改在長按：以詞定字 [／] ＝長按 u／i，萬用查字 ? ＝長按 /，注音反查 ~ ＝長按 b，符號選單 ＝長按 z；候選直接用點的。

常見問題

搜尋前，先看這裡。

拍台文適合完全不懂台文的人嗎？

如果會講台語、知道大概怎麼拼，就可以開始。候選拼音註解、聲調省略和華語反查，都是為了降低入門門檻。

一定要學 Telex 調鍵嗎？

不必。預設「拍台文(台)」用無調和數字調就夠用。Telex 是 F4 裡的平行進階方案，給熟台羅、想連續補調的人；詞典和輸出與主方案相同。說明與鍵位圖見Telex 一節。

這是手機輸入法嗎？

官方安裝包只有 Windows（PhahTaiBunSetup.exe）。macOS 用指令安裝（curl …/install_macos.sh | bash），Linux 用 ./install.sh。Android 沒有 APK：要先自己裝同文 Trime（F-Droid 或它的 Releases）或小企鵝輸入法 5 + RIME 外掛，再從本專案 Releases 挑一個包——PhahTaiBun-Trime.zip（拍台文＋注音）或 PhahTaiBun-Trime-liur.zip（再加嘸蝦米）——放進它的 Rime 使用者資料夾並重新部署；手機鍵盤的快捷鍵也不等於桌面。步驟見 Android 部署。

會覆蓋我原本的 Rime 設定嗎？

安裝流程會保留既有 Rime 輸入法、自訂詞庫與 rime.lua，再加入拍台文方案。

教育部輸入法的增補詞庫匯入後，操作方式也一樣嗎？

不一樣。拍台文只把有用的詞庫資料納入建置流程；操作仍維持拍台文設計：數字鍵打聲調，候選選字按 Tab 後用 asdfghjkl;，符號選單按反引號。
