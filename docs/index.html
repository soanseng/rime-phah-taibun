特色

從輸入到選字，簡單順手。Ti̍k-sik

01

白話字、台羅攏會通

免選拼音系統：tsiah、chiah lóng 揣會著「食」。

02

聲調先免拍

先打音節找候選，需要時才補數字調，親像 ho2。

03

候選標示讀音

選字時看得到拼音註解，順 sòa 確認讀音。

04

漢羅混寫，自動也手動

預設依 LKK 規範自動混寫；切「手動漢羅」後，佗一個詞欲寫羅馬字由你標記。

05

整句輸入，一次送出

打完整句羅馬字，按空白鍵就送出；中途嘛會當用 Tab 挑字。

06

標點、符號、Emoji 攏有

漢羅模式全形標點隨打隨上；` 開 50 類符號，`e 瀏覽 Emoji，拍「台灣」會當選 🇹🇼。

  • ? 萬用查字——任何位置攏會查音節
  • 字典查無？用 - 斷音節，Tab 逐字選，選字就是選調
  • -- 輕聲即時生成——「轉--來」「食--飽」無問題
  • 手動漢羅——Tab 反白詞按 \ 標記做羅馬字
  • Ctrl+標點 臨時翻轉標點寬度

安裝

先裝 Rime 核心，再加入拍台文。An-tsong

拍台文毋是另一個輸入法引擎，是 Rime 的台語方案：Windows 用小狼毫，macOS 用鼠鬚管，Linux 用 fcitx5-rime／ibus-rime，Android 用 Trime。

Windows：小狼毫 Weasel ＋ 安裝包抑是 PowerShell

  1. 一般使用者：對 Releases 載 PhahTaiBunSetup.exe 雙擊安裝。電腦猶無小狼毫 Weasel 的話，安裝包會順紲共伊裝好（會跳一擺系統管理員權限確認，揤「是」）。
  2. 抑是先家己裝小狼毫，才佇 PowerShell 貼：irm https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/install_windows.ps1 | iex（互動式：會問愛裝拍台文、嘸蝦米 rime-liur 抑是兩个攏裝；改設定進前先備份 default.custom.yaml，既有輸入法會當保留）。
  3. 系統輸入法切到小狼毫，重新部署 Rime，按 F4 抑是 Ctrl+` 選「拍台文(台)」。

macOS：鼠鬚管 Squirrel ＋ 指令（無 .pkg）

  1. 先裝鼠鬚管 Squirrel。
  2. 終端機貼：curl -fsSL https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/scripts/install_macos.sh | bash
  3. 嘛會 git clone 了後 ./install.sh，抑是共 schema/、lua/、rime.lua 抄到 ~/Library/Rime/ 重新部署。
  4. 輸入法切到鼠鬚管，按 F4 抑是 Ctrl+` 選「拍台文(台)」。

Linux：fcitx5-rime 抑是 ibus-rime

git clone https://github.com/soanseng/rime-phah-taibun.git
cd rime-phah-taibun
./install.sh

Android：拍台文 Trime APK（干焦佇 GitHub）抑是官方同文＋一鍵包

  1. 上省事：裝客製 APK——對 rime-trime-taigi Releases 載 arm64-v8a 版（大多數手機；模擬器用 x86_64），允許「安裝未知應用程式」了後裝起來。拍台文＋注音＋嘸蝦米攏預裝、介面繁體化、點候選直接上屏，長按中文鍵有拍台文面板，免閣部署。
  2. 愛自動更新：用 Obtainium——F-Droid 裝 Obtainium，加 app source https://github.com/soanseng/rime-trime-taigi，開「Filter APKs by CPU Architecture」（預設）就會揀著正確的架構，將來自動揣新版。
  3. 啟用「拍台文 Trime」輸入法，方案已預選，直接拍 gua beh khi tshit tho →「我 beh 去 tshit-thô」。漢羅↔全羅、TL↔POJ 長按中文鍵開面板切。

替代：官方同文＋一鍵包——F-Droid 裝 com.osfans.trime，對本專案 Releases 載 PhahTaiBun-Trime.zip（抑是加嘸蝦米的 -liur 版）解壓入 Android/data/com.osfans.trime/files/rime，重新部署了後揀「拍台文(台)」。 完整步驟、路徑佮按鍵對照。

創作者

一個人的計畫，予閣較濟人寫台文。Tsi̍t-ê lâng ê kè-uē

拍台文由 陳璿丞醫師 發起——一个屏東大漢囡仔，想共母語揣轉來，嘛想共台語書寫對「懂規則的人才會用」推向前「會講台語就會曉開始」。專案整合 Rime、ChhoeTaigi 詞庫、語料頻率、LKK 用字規範佮 22 个 Lua 模組。

本底我攏用嘸蝦米，用甲真慣勢；Linux、Windows、Mac 嘛用 Rime 用真濟冬。10 外年以前，我猶真菜的時陣，捌掠準講家己會曉寫一个台語輸入法——hit 陣失敗矣。這馬有 AI，資源嘛一年一年閣較濟，我就寫一个家己會用的：家己拍字的艱苦、學習過程的艱苦，攏囥佇這个輸入法內底，一邊開發、一邊重學。所以這个方案是照我的環境做的：嘸蝦米佮拍台文做伙用，主要 Linux 佮 Android，Windows 有時仔爾爾。後來閣用這套字典做姊妹站讀台文 Tha̍k Tâi-bûn：漢羅、TL、POJ 對照，會使查單字、讀文法筆記。

常見問題

拍字進前，先看這。Būn-tê

拍台文適合完全毋捌台文的人嗎？

若會講台語、知影大概按怎拼，就會曉開始。候選拼音註解、聲調省略佮華語反查，攏是為著降低入門門檻。

一定愛學 Telex 調鍵嗎？

免。預設「拍台文(台)」用無調佮數字調就夠額。Telex 是 F4 內的平行進階方案，予熟台羅、想連續補調的人；詞典佮輸出佮主方案相仝，說明見Telex 段。

這是手機輸入法嗎？

官方安裝包干焦 Windows（PhahTaiBunSetup.exe）。macOS 用指令安裝，Linux 用 ./install.sh。Android 有客製 APK「拍台文 Trime」，干焦佇 GitHub Releases（F-Droid／Google Play 攏無上架），拍台文＋注音＋嘸蝦米攏預裝、免部署，嘛會當用 Obtainium 自動追新版；抑是裝官方同文 Trime／小企鵝 5 ＋ RIME 外掛，閣對本專案 Releases 揀 PhahTaiBun-Trime.zip 一鍵包放入去重新部署。完整步驟見 Android 部署。

會蓋掉我原本的 Rime 設定嗎？

安裝流程會保留既有 Rime 輸入法、自訂詞庫佮 rime.lua，才加入拍台文方案。

教育部輸入法的增補詞庫匯入了後，操作方式嘛仝款嗎？

無仝款。拍台文干焦共有用的詞庫資料納入建置流程；操作猶原照拍台文設計：數字鍵拍聲調，候選選字按 Tab 了後用 asdfghjkl;，符號選單按反引號。
