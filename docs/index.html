特色

從輸入到選字，簡單順手。Ti̍k-sik

01

白話字、台羅攏會通

免選拼音系統：tsiah、chiah lóng 揣會著「食」。

02

聲調先免拍

先打音節找候選，需要時才補數字調，親像 ho2。

03

候選標示讀音

選字時看得到拼音註解，順 sòa 確認讀音。

04

漢羅混寫，自動也手動

預設依 LKK 規範自動混寫；切「手動漢羅」後，佗一個詞欲寫羅馬字由你標記。

05

整句輸入，一次送出

打完整句羅馬字，按空白鍵就送出；中途嘛會當用 Tab 挑字。

06

標點、符號、Emoji 攏有

漢羅模式全形標點隨打隨上；` 開 50 類符號，`e 瀏覽 Emoji，拍「台灣」會當選 🇹🇼。

  • ? 萬用查字——任何位置攏會查音節
  • 字典查無？用 - 斷音節，Tab 逐字選，選字就是選調
  • -- 輕聲即時生成——「轉--來」「食--飽」無問題
  • 手動漢羅——Tab 反白詞按 \ 標記做羅馬字
  • Ctrl+標點 臨時翻轉標點寬度

安裝

先裝 Rime 核心，再加入拍台文。An-tsong

拍台文毋是另一個輸入法引擎，是 Rime 的台語方案：Windows 用小狼毫，macOS 用鼠鬚管，Linux 用 fcitx5-rime／ibus-rime，Android 用 Trime。

Windows：小狼毫 Weasel ＋ 安裝包抑是 PowerShell

  1. 先裝小狼毫 Weasel。
  2. 一般使用者：對 Releases 載 PhahTaiBunSetup.exe 雙擊安裝。
  3. 抑是 PowerShell 貼：irm https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/install_windows.ps1 | iex（互動式：會問愛裝拍台文、嘸蝦米 rime-liur 抑是兩个攏裝；改設定進前先備份 default.custom.yaml，既有輸入法會當保留）。
  4. 系統輸入法切到小狼毫，重新部署 Rime，按 F4 抑是 Ctrl+` 選「拍台文(台)」。

macOS：鼠鬚管 Squirrel ＋ 指令（無 .pkg）

  1. 先裝鼠鬚管 Squirrel。
  2. 終端機貼：curl -fsSL https://raw.githubusercontent.com/soanseng/rime-phah-taibun/main/scripts/install_macos.sh | bash
  3. 嘛會 git clone 了後 ./install.sh，抑是共 schema/、lua/、rime.lua 抄到 ~/Library/Rime/ 重新部署。
  4. 輸入法切到鼠鬚管，按 F4 抑是 Ctrl+` 選「拍台文(台)」。

Linux：fcitx5-rime 抑是 ibus-rime

git clone https://github.com/soanseng/rime-phah-taibun.git
cd rime-phah-taibun
./install.sh

Android：先裝同文 Trime，閣放拍台文入去（無 APK）

  1. 先裝輸入法 App：F-Droid 裝 com.osfans.trime（上省事）抑是對Trime Releases 載 APK；替代：小企鵝輸入法 5 ＋ RIME 外掛。
  2. 對本專案 Releases 載一鍵包：PhahTaiBun-Trime.zip（拍台文＋注音）抑是 PhahTaiBun-Trime-liur.zip（閣加嘸蝦米，約 20 MB），解壓入 Android/data/com.osfans.trime/files/rime（Android 11+ 檔案總管入無去，請用電腦 USB／MTP 抑是同文內建檔案管理）；default.custom.yaml 已用 @next 追加好，免家己改。
  3. 同文選單 → 重新部署（頭一擺編譯字典幾分鐘，毋通共 App 滑掉）。
  4. 方案清單選「拍台文(台)」就會拍字；漢羅↔全羅、TL↔POJ 佇 App 開關面板切。長按：[/]＝長按 u/i、?＝長按 /、~＝長按 b、符號選單＝長按 z。

常見問題

拍字進前，先看這。Būn-tê

拍台文適合完全毋捌台文的人嗎？

若會講台語、知影大概按怎拼，就會曉開始。候選拼音註解、聲調省略佮華語反查，攏是為著降低入門門檻。

一定愛學 Telex 調鍵嗎？

免。預設「拍台文(台)」用無調佮數字調就夠額。Telex 是 F4 內的平行進階方案，予熟台羅、想連續補調的人；詞典佮輸出佮主方案相仝，說明見Telex 段。

這是手機輸入法嗎？

官方安裝包干焦 Windows（PhahTaiBunSetup.exe）。macOS 用指令安裝，Linux 用 ./install.sh。Android 無 APK：先家己裝同文 Trime 抑是小企鵝 5 ＋ RIME 外掛，閣對本專案 Releases 揀一个包——PhahTaiBun-Trime.zip（拍台文＋注音）抑是 PhahTaiBun-Trime-liur.zip（閣加嘸蝦米）——放入 Rime 使用者資料夾重新部署；完整步驟見 Android 部署。

會蓋掉我原本的 Rime 設定嗎？

安裝流程會保留既有 Rime 輸入法、自訂詞庫佮 rime.lua，才加入拍台文方案。

教育部輸入法的增補詞庫匯入了後，操作方式嘛仝款嗎？

無仝款。拍台文干焦共有用的詞庫資料納入建置流程；操作猶原照拍台文設計：數字鍵拍聲調，候選選字按 Tab 了後用 asdfghjkl;，符號選單按反引號。
