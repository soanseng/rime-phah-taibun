讀文章蓋趣味。

教育部《咱來學臺灣台語 讀文章蓋趣味》01、02 冊 59 篇台語短文，會使照漢羅、台羅、白話字抑是逐段對照來讀；手冊官方讀音標佇字頂，全文佮詞彙攏有原音，讀了就直接跳去打字練習佮聽寫。

來源佮授權

課文、詞彙、文法說明佮音檔攏出自教育部《咱來學臺灣台語 讀文章蓋趣味》01 冊 PDF、02 冊 PDF（教育部語文成果入口網）；短文出處是教育部電子報「臺灣閩南語我嘛會」、「閱讀越懂閩客語」單元。著作權屬教育部，本站照原文引用。

文字檔對 OpenFormosa/OpenTaigi（MIT），音檔對 Taiwanese-Corpus/Lan-Lai-Oh-Taigi 轉做單聲道 32 kbps MP3。台羅／白話字全文是寫台文轉換詞典自動轉換：手冊括號註明的詞用官方讀音，其他讀音可能有誤，請以音檔為準。
